# Dasqua catalog 2025 enrichment reports

Official source: DASQUA 2025 EDITION PDF (local operator path).

Generated by `scripts/dasqua_catalog_2025_enrich.py`.

| File | Meaning |
|------|---------|
| `site_export.csv` / `.jsonl` | Active Dasqua products from staging API (**commerce-stripped**) |
| `pdf_text_layout.txt` | Cached `pdftotext -layout` extract |
| `pdf_index.jsonl` | Per-SKU PDF row candidates |
| `match_report.csv` | matched / unmatched / conflict |
| `dry_run_payloads.jsonl` | Proposed PUT bodies (enrichment keys only) |
| `apply_report.csv` | Apply results (after `--apply`) |
| `summary.json` | Counts + `commerce_policy.zero_price_writes` |

Policy: very-high SKU match only; no invented specs; staging writes.

**HARD commerce constraint:** never read/persist/write `price`, `sale_price`,
`list_price`, `base_price`, `original_price`, `discount*`, `stock*`,
`availability`, `is_available`. PUT allowlist:
`short_description`, `description`, `meta_title`, `meta_description`,
`specifications` (technical_specs merge).
