# Category hub intros (SEO-002)

Persian buyer-intent intros for top metrology + cutting category hubs.

- **SoT file:** `intros.json`
- **Repo path:** also available as `content/hubs/` (symlink to this directory)
- **Consumed by:** Storefront `src/lib/hub-intros.ts` → `CategoryHubView`

## Rules

- Unique 150–300 word intros (whitespace-separated tokens)
- ≥3 internal links per hub (`/categories/…` or `/blog/…`)
- No price, stock, or availability claims
- Do not invent taxonomy; link only to real slugs
