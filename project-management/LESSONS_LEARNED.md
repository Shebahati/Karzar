# Lessons Learned

- [x] Parallel agents on one worktree corrupt branches — use git worktrees
- [x] RTL dialog `start-1/2` + `-translate-x-1/2` mis-centers — use physical `left-1/2`
- [x] Aggregated `product_count` is not safe for delete guards — count direct FKs
- [x] Category packshots can override curated heroes — prefer curated on marketing surfaces
- [x] Unicode regex `/u` broke storefront SWC parse — prefer string helpers
